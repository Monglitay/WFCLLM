双通道不是两套独立系统

它更像一套共享底座，上面挂两种不同类型的水印证据

生成端
LLM 生成代码
↓
共享底座：AST simple block 切分 + block contract
语义通道
编码器 + LSH
判断这个 block 的语义签名是否命中目标

特点：更鲁棒
词法通道
在 block 内找少量安全改写位点
例如等价写法 / 局部表达式变体

特点：更脆弱，但更容易补充检测信号
↓
输出同一份最终代码 + 双通道 metadata
检测端
输入：最终代码 + secret key
↓
重新做 AST simple block 切分 + block contract
语义检测分数
看 block 级语义命中率
词法检测分数
看 block 内词法位点命中率
↓
最后输出 3 个结果：语义分数 / 词法分数 / 联合分数
