# Legacy WFCLLM Archive 2026-07

This archive preserves the pre-mainline WFCLLM watermark, extract,
token-channel, adaptive-gamma, dual-channel, pretrain, and ablation code paths
for historical reproducibility.

New production code must not import from this directory. Default package code,
tests, and scripts use the mainline WFCLLM generation, semantic, detection,
audit, diagnostics, and method modules instead.

Large local data, model, checkpoint, logits, and raw experiment artifacts are
not tracked here.
